# Sound credits

All nine samples (`kick`, `snare`, `hihat`, `openhat`, `clap`, `tom`, `crash`, `ride`, `cowbell`) were synthesized from scratch for this project with a short Python script (standard library only: sine sweeps, filtered noise and square-wave partials, written as 16-bit mono 44.1 kHz WAV).

No third-party recordings are used, so there is no external license to attribute. The samples are original work and may be reused freely.
